# 왕전초 눈치왕 (Wangjeon Nunchi King)

글씨가 **칠해진 색**과 글자가 **말하는 색**이 서로 달라도, 이번 미션에 맞는 색을 눈치 있게 골라 내는 색깔 게임입니다.
`♡왕전초 연산왕!♡`·`♡왕전초 타이머왕!♡`와 같은 왕전초 시리즈예요.

**바로 플레이:** https://chohanui2-home.github.io/wangjeon-nunchi/

## 게임 규칙

파란 카드 안에 `빨강`, `파랑`, `노랑`, `초록`, `보라`, `주황` 같은 색깔 이름이 **다른 색으로** 크게 나옵니다.
카드 위 미션 배지가 이번 문제에서 무엇을 골라야 하는지 알려 줍니다.

- 🎨 **글씨 색깔 고르기!** — 글자가 '빨강'이라고 적혀 있어도 **파란색으로 칠해져 있으면 정답은 파랑**
- 🔤 **적힌 글자 고르기!** — 이번엔 반대로, **글자가 말하는 색**이 정답 (미션 배지 색과 아이콘이 확 바뀝니다)

## 6단계

| 단계 | 이름 | 색깔 | 문제 | 미션 |
|---|---|---|---|---|
| 1 | 색깔 3개 | 빨강·파랑·노랑 | 10 | 글씨 색깔 고정 (입문) |
| 2 | 색깔 4개 | +초록 | 10 | 글씨 색깔 고정 |
| 3 | 색깔 5개 | +보라 | 12 | 글씨 색깔 + 스피드 보너스 |
| 4 | 미션 반전! | 5색 | 12 | 글씨 색깔 ↔ 적힌 글자 랜덤 전환 |
| 5 | 버튼 섞기 | +주황 (6색) | 15 | 미션 전환 + 3문제마다 보기 버튼 위치가 살짝 섞임 |
| 6 | 눈치왕 30초! | 6색 | 30초 | 30초 타임어택, 미션 전환, 콤보로 최대한 많이 |

화면 맨 아래 탭에서 언제든 단계를 바꿀 수 있고, 별을 받은 단계에는 ★·♛ 표시가 붙습니다.

## 특징

- **매번 새 문제** — 6색 조합을 그 자리에서 만들어 냅니다. 글자와 글씨 색이 서로 다른 문제가 86%쯤 나오고, 직전 문제와 똑같은 조합은 연속으로 나오지 않습니다.
- **미션이 세 번 넘게 이어지지 않음** — 4~6단계에서 미션이 바뀌므로 계속 같은 답을 고르는 요령이 통하지 않습니다.
- **눈에 잘 보이는 색** — 문제 글자는 흰색 카드 위에 놓고, 여섯 색 모두 흰 배경에서 대비 3:1 이상(노랑은 골드 톤)으로 골라 읽기 쉽습니다. 보기 버튼은 색 원 + 한글 이름이라 색을 구분하기 어려워도 이름으로 고를 수 있습니다.
- **점수·콤보** — 정답 100점 + 연속 콤보 보너스(최대 +100) + 3단계부터 빠른 정답 스피드 보너스(최대 +80). 오답은 콤보만 끊깁니다.
- **결과 화면** — 별점, 점수, 정확도, 최고 콤보, 평균 반응 시간, **다시 도전 · 다음 단계 · 친구에게 공유하기**
- **기록 저장** — 단계별 최고 점수와 별점을 브라우저에 저장(최고 기록 갱신 시 '새 기록!' 표시)
- **혼자서도 재미있게** — 마스코트 두 마리의 표정 변화(환호·장난·다독임), 폭죽, 효과음(정답 딩동·콤보 상승·오답 띠용·클리어 팡파레, 음소거 가능)
- **앱처럼 설치** — 홈 화면에 추가하면 전체화면 앱처럼 열립니다
- PC에서는 숫자 키 `1`~`6`으로도 고를 수 있습니다

## 파일

- `index.html` — 게임 전체가 들어 있는 **단일 파일**. 외부 CDN·폰트·이미지 0개(그림은 인라인 SVG, 소리는 Web Audio API). 파일 하나만 보내도 그대로 열립니다.
- `app_template.html` — 빌드용 템플릿(아이콘 자리표시자 포함)
- `build.py` — 아이콘 주입과 단일 파일 규칙 검사 후 `index.html` 생성
- `test_app.py` — QuickJS로 게임 스크립트를 실행해 문제 생성 규칙·채점·콤보·타임어택·탭·기록 저장을 검사하는 테스트

## 다시 빌드하기

```bash
python3 build.py      # index.html 생성 (단일 파일 검사 포함)
python3 test_app.py   # 테스트 (quickjs 파이썬 모듈 필요)
```
